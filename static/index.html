How Adaption cleans the data before analysis

The uploaded CSV is sent to Adaption through its API (upload, run with deduplication, then evaluation and download). InsightFlow analyses only the cleaned dataset that comes back, so a smaller, higher-quality set drives every chart and recommendation. Raw counts are kept so frequency still feeds the priority score.
